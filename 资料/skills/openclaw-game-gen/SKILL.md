# 一句话游戏生成器（OpenClaw Game Gen）

> 用户的原话：「我跟这个 AI 说，我想玩一个什么什么游戏，它自动把我说的短短的提示词改成一段包含了场景描写、玩法过程等等描写的一个完整的提示词，之后再使用这个 skill 生成一个游戏，并且在我电脑里弹出一个这个游戏的界面，让我来玩儿。」

## 核心流程（4 步，全自动）

### 第 1 步：捕获短词 + 判定风格
- 从用户消息里抽出那句短游戏想法（可能就 2~8 个字，如"躲陨石""像素贪吃蛇""太空射击"）。
- **风格判定**：
  - 用户明确说了"像素/像素风/8位/复古" → 像素风（Canvas 方块绘制 + `image-rendering: pixelated`）。
  - 用户明确说了"几何/极简/简约" → 极简几何风（高饱和纯色圆/矩形/线条）。
  - **用户没说** → 默认极简几何风。
  - 用户说了具体题材（太空/恐怖/武侠/水墨…）→ 题材照做，风格仍按上面规则。

### 第 2 步：扩写提示词（关键！）
把短词套进下面的**完整提示词模板**，由模型在对话里直接产出一段 150~300 字、有画面感的完整游戏提示词。这段扩写要**展示给用户看**（大佬想看"短词怎么变完整提示词"），然后再进第 3 步。

**扩写模板（填空式，必须覆盖全部字段）：**
```
【游戏名】<根据短词起个带感的名>
【类型】<敏捷/解谜/射击/塔防/生存/音乐/文字…>
【场景描写】<3~4 句沉浸画面：世界观、环境、氛围、你身处何地>
【玩法过程】<核心循环：玩家每帧/每回合做什么、目标是什么、怎么算赢怎么算输>
【操作方式】<键鼠/触屏映射，越简单越好，1~3 个键>
【难度与节奏】<怎么随时间变难、有没有波次/计时>
【视觉风格】<像素 / 极简几何，配色基调和情绪>
【一句话钩子】<为什么上头>
```

### 第 3 步：生成自包含单 HTML 游戏
基于扩写后的完整提示词，**直接写代码**生成一个 `.html` 文件，硬约束：
- **零外部依赖**：不引任何 CDN、不引外部图片/字体/JS。所有美术用 Canvas 现画或 emoji/Unicode。
- **单文件**：CSS/JS 全内联，双击即开。
- **轻量**：机器 2 弱机也能跑，控制逻辑规模（通常 150~400 行），不堆粒子不堆贴图。
- **可玩闭环**：有开始、有实时游戏循环（requestAnimationFrame）、有操作响应、有分数/胜负、有重开。
- **像素风实现**：用 `ctx.fillRect` 画方块网格 + `image-rendering: pixelated`；或低分辨率离屏 canvas 放大。
- **几何风实现**：`ctx.arc/fillRect/lineTo` 纯色形状，高饱和配色，留白干净。
- 顶部留一行说明：游戏名 + 操作键 + 目标，5 秒内看得懂。
- 文件保存到：`C:/Users/baoka/.workbuddy/skills/openclaw-game-gen/games/<游戏名>.html`
  （`<游戏名>` 用英文或拼音文件名，空格转下划线）

### 第 4 步：原生窗口弹出来玩
调用本 skill 的 `spawn_window.py`，传入上一步的 html 绝对路径：
```
C:/Users/baoka/.workbuddy/binaries/python/versions/3.13.12/python.exe ^
  C:/Users/baoka/.workbuddy/skills/openclaw-game-gen/spawn_window.py ^
  "<html绝对路径>"
```
- `spawn_window.py` 会优先用系统 WebView2（pywebview）弹**独立原生窗口**；若 WebView2/pywebview 不可用，自动回退用系统默认浏览器打开。
- 用 Bash 工具以 **run_in_background** 启动该脚本，让游戏窗口独立运行、不卡住对话；用户关窗即结束。

### 第 5 步（收尾，必须做）
- 把本次生成的游戏 HTML **复制到 U 盘游戏成品目录**：`G:/资料/游戏成品/<游戏名>.html`
  （若 `G:/资料/游戏成品` 不存在则 `mkdir -p` 创建）。
- 向大佬报告：游戏名、扩写后的完整提示词要点、操作键、窗口已弹出、U盘备份路径。

## 自检清单（生成后、弹出前，逐条确认）
- [ ] html 是单文件、无 `<script src=`、`http(s)://` 外链（允许 `data:`）
- [ ] 有 `<canvas>` 且有 `requestAnimationFrame` 循环
- [ ] 有键盘/鼠标监听且能改变游戏状态
- [ ] 有分数或胜负判定，能重开
- [ ] 顶部有游戏名 + 操作说明
- [ ] 机器 2 弱机跑得动（无大循环无外部资源）

## 边界
- 不本地跑大模型（机器 2 带不动），所有"扩写+生成"由本对话的模型在对话里完成，弹窗只是外壳。
- 不联网取资源，全离线可玩。
- 若用户一句话其实是要改已有游戏/调试，先问清再动。
