# 图片生成器 Skill

## 概述

调用 ImageGen 工具，把用户的文字描述（或空描述）转换成**高质量、成片感强、强制彩色**的图片。

本 Skill 的核心不是"会调一个出图工具"——那谁都会。核心是**提示词工程**：模型默认在提示词模糊时会偷懒，输出扁平、粗糙、像小孩随手涂两笔的图。所以本 Skill 强制在每次出图前，把输入重构为一句**锚定风格 + 强制彩色 + 完成度质量标记 + 负向排除**的专业提示词，从根本上杜绝"涂鸦感"。

默认风格：国风彩墨画（彩色水墨，不是黑白）。用户给了具体描述则按描述具体化生成，但仍套用同一套质量增强与彩色强制规则（游戏背景除外，见下文"彩色强制规则"）。

## 触发条件

用户说出/输入类似以下内容时立即加载本 Skill：

- "给我画一张 XX"
- "生成一张图片：……"
- "帮我生个游戏素材/立绘/背景"
- "来张国风水墨图"
- "画个 XX 的插图"
- "generate/draw/make an image of …"
- 任何"用 AI 出张图"的意图

## 核心理念：为什么本 Skill 出的图不像小孩涂鸦

出图质量 ≈ 提示词信息密度 × 风格锚定强度 × 完成度标记。本 Skill 在每次调用前强制补齐三块拼图：

1. **风格锚定（Style Anchor）**——必须点名一个具体的专业媒介/流派（如"传统中国工笔彩墨画""数字概念艺术""商业插画"），不让模型自己选"简单插画"这种低保真默认。
2. **完成度质量标记（Finish Markers）**——明确写"成片/精修/完成度高的作品，不是草图、不是线稿、不是草稿"。
3. **负向排除（Negative Guard）**——在提示词里写明"不要：粗糙、业余、儿童画、 Stick-figure、涂鸦、低完成度、潦草"。

详见 `references/style-prompts.md`（提示词词库与模板）。**每次出图前先读这个文件**，按里面给的词库和模板拼装提示词。

## 工作流程

### 第 1 步：判断输入类型

根据用户输入，分三类处理：

- **A. 有文字描述** → 进入第 2 步，把描述具体化、专业化。
- **B. 无描述 / 只说"画一张""来张图"** → 直接用 `references/style-prompts.md` 里的「默认彩墨提示词模板」，进入第 3 步。
- **C. 带参考图（用户给了本地路径或 URL）** → 走 image-to-image 分支：把参考图作为 `image` 参数传入，提示词写"基于参考图，重绘为 [目标风格/配色]，保持 [构图/主体]"，并设 `input_fidelity` 控制还原度（重绘风格设低 0.3–0.5，保构图设高 0.7–0.9）。

### 第 2 步：把描述重写成专业提示词（核心）

按 `references/style-prompts.md` 的「提示词构造公式」组装，公式结构：

```
[主体与场景细节] + [构图与镜头] + [光影] + [色彩强制(彩色)] + [媒介/风格锚定] + [完成度质量标记] + [负向排除]
```

操作要点：

1. **具体化**：用户说"一条龙"→ 扩成"一条盘旋于云海之上的金鳞青龙，龙须飞扬、爪踏浪花、鳞甲反光"；用户说"森林"→ 扩成"晨雾中的针叶密林，光束穿过树冠、地衣覆石、远处溪流"。越具体，越不像涂鸦。
2. **套用风格锚定**：除非用户指定，否则默认套「国风彩墨」锚定；若用户要其他风格（赛博朋克/像素/厚涂等），从词库选对应锚定。
3. **强制彩色**：在提示词里明确写 `full color, vibrant, richly saturated`，并从词库选一组配色。除非命中"彩色强制规则"的例外（游戏背景），绝不输出黑白。
4. **加质量标记与负向排除**：从词库粘贴 `masterpiece, best quality, ultra-detailed, 8k, sharp focus` 等，以及 `not a sketch, not a child's drawing, not crude, no doodle`。

> 若用户描述本身已经非常详细专业，可在此基础上只补"彩色强制 + 质量标记 + 负向排除"三块，不重写用户原意。

### 第 3 步：调用 ImageGen

用 `DeferExecuteTool` 调用 `ImageGen`，参数建议：

- `prompt`：第 2 步拼好的完整提示词（英文优先，混合中文风格词也可；模型对英文风格词理解更好，关键风格词保留中文拼音/英文如 "gongbi color ink painting"）。
- `quality`：`"high"`（质量优先，杜绝糊图）。
- `size`：游戏素材常用 `"1024x1024"`（方块/立绘/贴图）；横版背景用 `"1536x1024"`；竖版海报用 `"1024x1536"`。用户没说就默认 `1024x1024`。
- `n`：默认 `1`；用户要"来几张挑挑"可给 `2`–`4`（注意积分消耗）。
- `style`：可填风格词（如 `"Chinese color ink painting"` / `"concept art"`），与 prompt 内锚定一致即可；不填也行，prompt 已含锚定。
- `revise`：`false`（我们已手工写好高质量 prompt，不让模型擅自改写，避免它把"彩色强制"改没）。
- `background`：一般 `"opaque"`；做贴图要抠图再设 `"transparent"`。
- `output_dir`：留空则用工作区默认 `generated-images/`；也可指定到用户项目目录（如游戏素材文件夹）。
- `image` / `input_fidelity`：仅第 1 步 C 类（带参考图）使用。

### 第 4 步：交付与校验

1. 出图后，用 `present_files` 把图片直接展示给用户。
2. **自检**：图是否彩色？主体是否清晰、有细节、有成片感？有没有意外的"涂鸦/草图/粗糙"味？
   - 若仍偏潦草/扁平 → 在 prompt 补更强质量标记（"hyper-detailed, octane render, unreal engine 5 style lighting"）和更具体的主体描述，重出一张。
   - 若意外变黑白 → 确认 prompt 含 `full color`，并把 `not monochrome, not black and white` 加进负向排除，重出。
3. 顺口问一句：要不要再来几张不同角度/配色，或转成游戏贴图（透明背景）、或做成网页/桌面应用？

## 彩色强制规则（重要）

- **默认且强制：彩色。** 几乎所有出图都带 `full color, vibrant, richly saturated` + 一组明确配色。用户明确说"黑白/水墨黑白/线稿"才出黑白。
- **例外——游戏背景**：若用户指明"这是游戏背景/地图底图/UI 底"，允许输出黑白或低饱和水墨（符合用户原话："游戏背景的话没关系"）。此时在 prompt 写 `monochrome ink wash` 或低饱和，但仍保持高完成度（不是潦草）。
- **用户原话提醒**：用户觉得纯黑白"看着不吉利"，所以非背景类一律彩色，别自作主张出黑白。

## 默认彩墨提示词模板（无描述时直接用）

见 `references/style-prompts.md` 的「默认彩墨提示词模板」一节，复制后按需求微调即可，无需每次重写。

## 输出规范

- 出图后用 `present_files` 展示，并给一句中文说明（风格 / 配色 / 用途建议）。
- 提示词如果用户想看，可附在回复里（方便他二次微调）。
- 口语化、直接，不废话。
- 注意积分：每次出图前提醒自己 `n` 别开太大；用户要"多来几张"时顺带提一句消耗。

## 注意事项

- ImageGen 是云端 API 调用，本机（含弱机）不会卡顿，放心跑；但它是重积分消耗，别无脑刷图。
- 若 ImageGen 调用失败/需要授权 → 如实告诉用户，不要假装出图成功。
- 游戏素材建议导出透明背景版（`background: "transparent"`）方便直接进引擎。
- 风格词中英混用效果最好；纯中文长句模型可能漏细节。
- 同一批生成多张素材图时，让各 prompt 开头明显不同。ImageGen 自动命名会截取 prompt 前缀，若两张图前缀相同可能覆盖同一路径导致丢失。
- 出图后检查右下角是否带「图片由AI生成」类水印。若用于应用/游戏背景、贴图等最终成品，先用 PIL 裁剪底部水印区域，避免反复出现或影响平铺。
