# 事件：钓鱼游戏布局 BUG 大战 + 功能收尾

日期：2026-07-12 至 2026-07-13
项目：悠闲钓鱼（Electron 单 HTML 游戏）

## 做了什么
一整晚围绕「布局模式拖拽导致背景/UI 抖动、缩小、塌缩」这个顽固 BUG 反复排查修复，并顺带完成多个功能。

## 过程（时间线）
1. 松手自动保存但不退出——移除点击即退出逻辑。
2. 背景会动——尝试截图冻结 → 占位符 → 最终 min-height 锁定 + flexbox 方案。
3. 标题「悠闲钓鱼」往下掉——`.title{align-self:flex-start}`。
4. 布局完页面缩小——退出时不解锁高度，重开重新锁。
5. 底部图例栏乱动——移出可移动面板列表（从 MOVABLE_ELS 删掉 bottom）。
6. raf 异步锁把高度永久锁死——加 unlockAllParents 兜底清 DOM。
7. 用户用 bug-fixer skill 复检，继续收敛，最终用户确认「试过无数次了，可以去睡觉了」。
8. 上鱼概率改为按百分比随机（Math.random()<fishPull）。
9. 关闭时弹窗选「最小化到托盘 / 直接关闭」。
10. 浏览器横屏顶部被截断——body 顶对齐可滚动。
11. 鱼种从 26→68→180，垃圾分布 湖泊>海洋>深渊。

## 结果
- 布局系统多轮重构后稳定，用户满意。
- 全部功能（托盘、随机概率、横屏适配、180 种鱼）按要求完成。
- 所有改动同步到 eve-app 及 release 两个路径。

## 教训
- 单 HTML 拖拽布局，脱离文档流后父容器塌缩是核心难点；flexbox 骨架 + min-height 锁 + 严格的「进锁/退不解锁/重开重锁/重置全清」闭环才稳。
- 重构时容易丢掉之前修好的小修复（如 title 固定），改完要回归验证旧 BUG 是否复现。
