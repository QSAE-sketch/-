# 2026-07-13 晚 QQ 机器人拉进自建小群（本机 青少年）

## 背景
- 本机「青少年」实例此前已连上 QQ 官方机器人，初连走频道/单聊，私聊已能远程指挥 WorkBuddy。
- 大佬想把该机器人拉进自己建的、≤20 人的小群，在群里 @机器人 远程指挥。

## 现状判定：情况 B
- 之前是频道/单聊连的，群里还找不到这个机器人 → 需先在后台开群场景权限（沙箱配置选群），再回手机 QQ 加。
- （情况 A = 已在某群能用，直接群设置加；情况 B = 需后台配置。本次属 B。）

## 操作结论（已给大佬）
1. 电脑开 bot.qq.com → 进机器人 → 开发 → 沙箱配置 → QQ 群 ID 选该 ≤20 人群（须是群主、成员≤20，机器人算人头）。
2. 保存后手机 QQ → 群设置 → 群机器人 → 找到机器人 → 添加。
3. 群里 @机器人 测试 WorkBuddy 是否响应。
4. 正式/长期用：使用范围与人员 → 群 → 设"全量"（审核）→ 群主可加任意群。

## 关键前提与风险
- ≤20 人小群正好满足 QQ 开放平台沙箱群条件（群主 + 成员≤20）。
- 机器人昵称大佬暂未透露。
- 代价重申：该端机器人收发须本机电脑 + WorkBuddy 应用一直开着（关机/退应用=下线），非云端托管。
- 群场景接口有阉割（被动消息5分钟有效期、部分 API 不全），简单指令 OK，复杂长对话可能受限。
- 新建号可能暂未开放群功能（改版频繁），已连 WorkBuddy 并能私聊指挥的基本排除。
