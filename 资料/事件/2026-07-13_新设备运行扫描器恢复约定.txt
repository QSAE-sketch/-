# 2026-07-13 新设备运行扫描器恢复记忆库约定

## 背景
- 大佬今天早上换到另一台电脑，在那边安装 WorkBuddy 并命名为「少年」，登录同一账号；担心云端数据传不回来。
- U 盘「记忆库」即为"跨设备不丢约定"的便携知识库兜底。
- 本任务：在本机识别并同步该记忆库，验证扫描器脚本，把约定固化进本会话长期记忆。

## 过程
1. PowerShell 枚举卷 → 发现可移动磁盘 E: 卷标「记忆库」(exFAT, 58.6GB)。
2. 只读扫描盘内文件，定位 `验证/scan_memory_library.py`（记忆库扫描器）。
3. 先拆读脚本确认纯只读（扫盘符找哨兵 __WORKBUDDY_KB_ID__ + UUID，命中后打印 RULES.md），再实跑验证：Exit Code 0，输出完整 RULES.md，无副作用。
4. 同步读取 workbuddy-kb（index.md + 3 主题：QQ通道 / 元器角色扮演 / 机器2避让）、资料库结构（资源 / 事件 / 游戏成果 / 资料总记录.txt）。
5. 将"记忆库识别方法"与"机器2避让规则"写进用户级 ~/.workbuddy/MEMORY.md（本机此前缺机器2规则，已补）。

## 成果
- 记忆库在线 @ E:，约定已恢复并持久化；下次搜不到东西会自动扫盘复用。
- QQ机器人.txt 含凭据，全程未读未打印，已提醒大佬勿明文存 U 盘。
