## 全链路（工作区 11-38-56，跨 7/24–8/7）
1. 输入框焦点：Tkinter override-redirect 拿不到 X 焦点 → `focus_force()`。
2. 无管理员改 squashfs/ISO：squashfs-tools-ng 在 MINGW64 无管理员编译 → tar 中转绕开 NTFS 大小写 / symlink 死结（sqfs2tar → Python tarfile 流式改 → tar2sqfs → xorriso 回灌）；xzhrio -map 语义坑。
3. WebView 版：剪贴板 / 壁纸 / 视频 / 浏览器 / 右键菜单 / 记事本落盘 / 商店服务端 `registry_server` 接入，烤进 ISO。
4. 持久化：rootfs 纯 live 无法装硬盘 → persistence 标签 ext4 分区 overlay；`merge_persist.py` → MyOS-persist.iso。
5. 输入法：根因 rootfs 无中文输入法 → fcitx5 注入（361 个 deb）两次失败（连英文被吞）→ 换**应用层拼音** `ime.py` + PinyinIME（Ctrl+Space / F8 弹窗，英文不碰键盘）；删全部 IM 环境变量。踩坑：pypinyin 字节要 gb2312 解码、tar2sqfs 二进制丢失改 sqfstar。
6. 改登录账号（用户1 / 密码2）重烤 ISO：`mod_user.py` 流式改 rootfs tar（passwd / shadow / subuid）+ openssl passwd -6。
7. 商店服务器起停 + 清理旧产物。
