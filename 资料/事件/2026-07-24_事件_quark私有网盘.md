# 2026-07-24 quark-netdisk 个人私有网盘（零依赖 Node 全栈）

## 做了什么
- `server.js`（端口 8787）：单密码 / 目录隔离 / 流式上传 / Range 视频 / 分享链接 / 路径穿越防护 + 暗色前端。
- 修 `pepper` 写死、`resolveSafe` 漏 hidden file bug。
- 自写 ZIP 打包下载（手写 CRC32，避免外部依赖）。
- 打包：PyInstaller + pywebview → `QuarkDisk.exe`（46MB）。
- 新功能：多用户 / 搜索 / 离线下载。
- 远程：`cloudflared` 被墙 → 改用 `ssh localhost.run` 隧道；安卓 APK 走 GitHub Actions；PWA 可加主屏。
- 两实例分开（appdata vs 项目 storage）。

## 状态
应用 + 远程全做完，可部署使用。
