# 2026-08-07 事件：C盘爆满清理危机（机器2 LAPTOP-6NCCT3NN）

## 背景
机器2 C盘 184.7GB 仅剩 5.25GB（97%），系统告急。大佬语音指示清理。

## 过程
1. **诊断**：用容错递归扫描定位大头（方法见资源/发现：2026-08-07_C盘爆满诊断与清理方法）。
2. **大佬逐项授权**：微信随便清、WSL保留、桌面"无用"自管、安卓模拟器可清、MyOS.iso保留、应用缓存随便清。
3. **执行清理（非提权，纯用户级操作）**：
   - 用户级 Temp / INetCache / npm-cache / 回收站
   - 安卓模拟器 3.63GB（删，因大佬已备份到 D盘）
   - 应用缓存/崩溃转储/D3DSCache/各 *-updater 约1.45GB
   - 微信媒体（Image+Video）6.82GB
   - 微信接收文档（File）2.96GB（后续大佬确认：文档可删、聊天记录不删）
4. **大佬澄清**：安卓模拟器与下载器已备份到 D盘，故 C盘对应项可删；但 D盘上的备份本身不删（已写入长期记忆 MEMORY.md 删除红线）。

## 成果
- C盘可用 **5.25GB → 20.65GB**，累计腾约 15.4GB，危机解除。
- 按大佬要求保留：WSL 15.83G、桌面"无用"13.21G、MyOS.iso 1.9G、Local\Programs（Ollama/VS/Quark）。

## 遗留 / 可选
- WSL 可 compact 回收空间（需管理员 PowerShell，本机非提权做不了）
- Quark 3.81G 最大且不怎么用可再议
- 桌面"无用"13.21G 大佬自己看着删

## 新规则（已入长期记忆 MEMORY.md 删除红线）
- D盘备份的「安卓模拟器」「下载器」不删
- 微信：聊天记录不删、接收文档可删
