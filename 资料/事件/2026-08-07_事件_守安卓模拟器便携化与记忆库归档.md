# 事件 · 2026-08-07 守安卓模拟器便携化根治 + 记忆库归档

## 背景
- 大佬因 C 盘爆满（剩 5.25GB），手动把模拟器/下载器从桌面（C）挪到 D 盘。
- 挪完发现：模拟器 exe 仍去 C 桌面找 runtime，导致 C 桌面又冒出空壳离线版文件夹；直接双击 D 盘 exe 可能起不来、或又把几 GB 下回 C。

## 诊断
- paths.py 的 RUNTIME 本就是相对路径（跟着 exe 走），并非写死 C。
- 真正写死 C 的有两处：
  ① deps.py `discover_other_runtimes` 硬编码 `home/Desktop/守 · 安卓模拟器-离线版/runtime` —— 联网版据此去 C 找离线版，找不到就建空壳。
  ② qemu.py 的 ASCII 中转 junction 层落在 `C:\用户目录`（虽只几 KB reparse 点，仍属 C 残留）。

## 修复（根治）
- 改 deps.py：离线版 runtime 改为按 exe 所在目录自动推导兄弟目录（扫描 RUNTIME.parent.parent 下含「离线版」的兄弟目录）。
- 改 qemu.py：`_JUNC_ROOT` 从 `Path.home()/.shou-emu-junc` 改为运行时所在盘根（如 `D:\.shou-emu-junc`），纯 ASCII、不占 C。
- 顺手修构建：build_exe.spec 有整段重复 Analysis/EXE（会静默产出错包），去重；补全 icon.ico。

## 重打包 + 部署
- 环境：envs/default python（含 PyInstaller 6.21 + webview，已确认 edgechromium.py 的 WEBVIEW2 补丁仍在）。
- 产物：onedir `dist/守安卓模拟器/{守安卓模拟器.exe(5.2MB), _internal/}`。
- 部署到 D：`D:\守 · 安卓模拟器-离线版\`（补回被清理任务误删的 exe+_internal，runtime 原样保留）、`D:\守 · 安卓模拟器-联网版\`（覆盖）。

## 验证（实测）
- 启动 15s：进程存活、Responding=True（WebView 正常）。
- C 桌面离线版文件夹 mtime 纹丝未动（仍 15:50:24）→ 新代码完全没碰 C。
- RUNTIME 自动解析到 D 同目录；junction 层会建在 D 盘根。
