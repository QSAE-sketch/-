# 2026-09-01 Godot 游戏开发课程（渐进式教学）

## 背景
大佬下载了 Godot 4.7.1 stable（安装包已在 U 盘：资料/游戏成果/O啥的选文件/Godot_v4.7.1-stable_win64.exe.zip），想从零学用 Godot 做游戏。自述"学过一丢丢 Python 但不多，当没学"，有 TurboWarp/Scratch 背景，要求用中文教学、类比 Scratch 理解最快。

## 课程约定（大佬定）
- 分课渐进，每课讲一点点
- 每课留作业，必须交作业才能开下一课
- 每几课安排一次"大项目"考试（做得出=掌握，做不出=不掌握）
- 中途有新创意可问"怎么加"，但不能直接开下一课（只告诉用什么做）
- 尽量中文，特殊变量名/语法保留英文原词
- 不主动给完整示例（用户问才给）
- 不要反复强调"课题外/作业未交"等程序性提醒（大佬自称天才，自己懂进度）

## 过程
- 第1课：GDScript 语言 + 项目/节点/场景/脚本概念 + _ready()/_process()/print()。作业=新建项目用 _ready() 打印三行不同文字。✅ 已完成（截图确认输出三行：启动啦！/乱码字符串/我今天看见昂扬向进！）
- 第2课：变量 var / String·int·float·bool / 类型标注 / 修改 / str() 拼接。作业=三个变量(名字/分数/在线)一句话打印 + 分数加50再打印。进行中（用户卡在：var 拼成 ver、变量名用纯数字 1/2/3、str 未加括号写成 str 1；已纠正，并澄清 Python3 也支持中文变量名、变量名不能以数字开头是语法硬规则）
- 创意答疑（不计入正式课）：
  * 信号 Signal 机制（signal 定义 / emit 发送 / connect 接收 / func 接收函数）——用于初始化、开始界面
  * 输入检测：按钮 pressed 信号 / 鼠标 _input(event) / 角色 Area2D+CollisionShape2D 的 input_event 信号
  * Inspector 英文属性名能否汉化 → 否（属性名即 API 名，改显示需改 C++ 源码重编译，机器1无编译器；建议学英文或用 EditorInspectorPlugin 做显示层映射；自己脚本可用中文变量名直接显示中文）
  * Python 转译 GDScript → 不推荐（等于造编译器）；给 godot-python（第三方）/ C#（官方）/ 直接学 GDScript 三条路

## 成果
- 大佬能独立创建 Godot 项目、写脚本、用 _ready()+print 输出、定义变量并打印
- 建立了 Godot 渐进式教学课程框架
