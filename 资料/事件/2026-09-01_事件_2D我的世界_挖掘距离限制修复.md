# 事件：2D 我的世界 · 挖掘距离限制（"手太长"）修复

- 日期：2026-08-16 起做，2026-09-01 归档
- 项目：`D:\2D我的世界\game`（Godot 4.7.1，GDScript 2.0）
- 触发：大佬反馈玩家"手太长"——挖方块能从地图这边挖到那一边（隔大半个地图挖），不是精灵贴图太长，是挖掘距离没有有效上限。

## 核查结论

挖掘 / 放置 / 交互的**唯一入口**是 `Player._handle_interaction(delta)`（由 `_physics_process` 调用）。
内部已有距离判定：以玩家眼睛位置（头部下方 20px）到目标方块中心的欧氏距离
`≤ reach() * TILE` 才允许，超出则 `_reset_mining()` 并 `return`；
`_do_use`（放置 / 开容器 / 点火 / 激活末地门）也在该 gate 之后执行，同样被限制。

→ 代码层面早就有距离限制。大佬体验到的多半是更早的构建，或旧值（生存 5 格 / 创造 9 格）给得太松，手感像无限远。

## 本次改动（`scenes/Player.gd`）

- `SURVIVAL_REACH` 5.0 → **4.0**，`CREATIVE_REACH` 9.0 → **8.0**（收紧臂长）。
- 把判定抽成独立方法 `target_in_reach(t: Vector2i) -> bool`，便于复用与测试。

## 验证（无头测试台 `tests/Harness.tscn`）

新增 `_probe_reach()`，直接调 `target_in_reach(near/far)` 实测：

```
reach=4.0 tiles (survival); near(3格)_in_reach=true; far(40格)_in_reach=false
[ok] reach gate works: 远处方块被拦截，无法隔图挖方块
```

全量探针（世界生成 / 背包 / 挖掘放置 / 合成 / 生物 / 存档 / 末地门+末影龙 / 酿造 / 玻璃瓶配方）仍全绿，零解析错误。

## 顺带修的坑

Harness 探针初版报 `Parse Error: Cannot infer the type of 'r_near'`：
`world.get_node_or_null("Player")` 返回 Variant，导致链式方法返回值类型推不出。
修复：给接收变量显式标注类型（`var r_near: bool` / `var eye: Vector2` / `var far_dist_tiles: float`）。
