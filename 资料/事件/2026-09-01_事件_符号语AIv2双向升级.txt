# 事件：上古混沌符号语 AI v2.0 双向升级（MoE 训练）

日期：2026-09-01（训练于 08-20 ~ 08-22 分次完成）
项目路径：D:\符号语AI训练\

## 背景
大佬的需求（8/20 提出）：
1. 符号语 AI **双向化**——用户和 AI 都用符号语交流（原来只有 AI 说符号语）
2. 重新生成语料 + 重新训练
3. 模型规模"尽量大"：最初想要专家 1B / 路由 1.5B

## 过程
1. **可行性评估**：本机 RTX 5060 8GB 显存 + 15.8GB 内存 → 1B 从零训练需要 24GB+ 显存，本机极限约 **专家 200M / 路由 300M**。大佬认可，关掉游戏腾显存。
2. **C++ 方案否决**：本机无 MSVC Build Tools，只有 MinGW g++；NVIDIA nvcc 官方只支持 MSVC 编译 host 代码，MinGW 从 CUDA12 起不被支持 → 走 Python + torch cu128（wheel 自带 CUDA runtime，无需单独装 CUDA Toolkit）。
3. **语料重生成**：gen_corpus.py 重写为双向问答族（BIDI_QA：问句 VSO/答句 SVO 模板 + 槽位笛卡尔积 + 多轮拼接 + 变体引擎）→ **18,135 条纯符号语↔符号语对话**（greet 3034 / game 2117 / time 5163 / family 3654 / shop 4167）。
4. **性能优化**：MHA 慢路径（8.8s/步）→ SDPA flash（0.82s/步，提速 12 倍）；head_dim 必须 64 倍数。
5. **训练**：greet（1920 步，loss 0.17）、router（2000 步，acc 100%）、game（1920 步，loss 0.15）。time/family/shop 未训（大佬要求改天）。

## 成果
- 双向符号语聊天系统 v2.0 可用：中文输入自动转符号语，或直接输符号语；路由判话题 → 专家用符号语回复，附中文译文。
- 已训好：greet + game 两个专家 + router 路由（100% 分流）。
- 实测：中文"你吃了吗"→`@ ( 〆`→回`! ( 〆`（我吃了）；"你玩游戏吗"→路由 100% 游戏世界→回"我玩游戏"；纯符号语 `♟ @ [`→`! ♟ [` ✅

## 遗留
- time/family/shop 三个专家待训（每主题 1920 步 ≈ 27 分钟）：`python train.py --topic time` 等。
- 缺专家的旧 v1.1 模型会被 chat.py 容错跳过，不崩。
