轻聊 3.0.0 · 安卓原生端整体重做
日期：2026-11-28
提交：f961350（源码 + 说明 + 版本号）

一、背景
大佬给出的三张手机端截图（深蓝方角、五个页签、网盘页、设置页）被认定为「幻想中的手机版」，
并明确：手机版不做功能限制，只要兼容 Android 5.0.2；不要完全照搬 OPENWIRE 示例。

二、这次做了什么
1) 架构：从「单页列表 + XML 布局」改为「代码绘制 + 五页签」。
   - MainActivity 只做壳：顶栏、内容区、底部页签（主页/房间/好友/网盘/我的）。
   - 页面拆成 HomePage / RoomsPage / FriendsPage / DrivePage / MePage，
     聊天、设置、皮肤中心各自独立 Activity。
   - 删除旧 MsgAdapter 与全部 XML 布局、旧 drawable。
2) 设计系统 Ui.java：深蓝底（#0C1522）、方角（2–6dp）、细描边；
   两套基础色 + 皮肤解析；卡片/按钮/标签/头像/进度条/自动换行容器/月亮按钮统一在这里。
3) 网盘（原生端首次具备）：配额、我的文件/回收站/我的分享、搜索、类型与目录筛选、
   上传（分片续传）、新建目录、移动/重命名/回收站/恢复/彻底删除、分享复用已有链接与随时下线。
4) 聊天：文字/图片（内联）/文件、增量轮询（since=rev，2.5s）、撤回、成员面板、
   站长金色流光（设置里可关，关后保留金色不闪动）。
5) 皮肤：不加载 CSS，解析网页皮肤 CSS 的变量。关键坑：CSS 里浅色与深色是两套块，
   必须整块取（:root 与 :root[data-theme="dark"]），混取会出现「浅顶栏 + 深正文」的花屏；
   另外对 --accent 做对比度兜底，避免深底上看不清。57 套内置皮肤都能换色。
6) 设置：主题三档（跟随系统/按时间/手动）、金色流光、清除缓存、清除本机聊天记录、
   下载位置、服务器地址、关于与更新记录。
7) 兼容：minSdk 19→21（Android 5.0.2+）。
   Android 5.x 不支持深色状态栏图标，浅色主题下把状态栏压成深色，避免白底白图标看不见。

三、验证
- 环境：Android 5.0.2（API 21）x86 模拟器，768×1280 / 320dpi。
- 逐页截图核对：主页、房间、好友、网盘、我的、设置、聊天、皮肤中心、登录页。
- 交互实测：登录成功进入主界面；发消息并增量出现；网盘文件弹层（下载/分享/移动/重命名/回收站）；
  分享链接弹层（链接/提取码/有效期/下载次数/复制/下线）；皮肤应用后整站换色；深浅两套配色均正常。
- 产物：Release APK 154552 B（约 151 KB），versionName 3.0.0 / versionCode 36，minSdk 21。
- 归档：资料/游戏成果/轻聊/轻聊-v3.0.0.apk（另存 Downloads），旧版 v2.7.1 留档。

四、过程中的问题与修正
- 顶栏月亮/太阳用字符 ☾ 在 API 21 字体里是方块 → 改为 Canvas 自绘月牙/太阳。
- 类型筛选标签在 360dp 宽度下被截断 → 改用自写 FlowRow 自动换行。
- 皮肤首版混用浅/深变量块 → 按模式整块解析。
- 聊天页/皮肤页进入时键盘自动弹出 → 设置 STATE_HIDDEN 并 clearFocus。
- 文件列表里的 share 对象没有 url 字段（只有 shareId）→ 统一补 /s/<shareId>。
- 勾选框默认绿色与整体不搭 → 统一 tint 成主题色。
- 版本号显示：改为读 APK 自身 versionName，避免「客户端 3.0 显示线上 2.9」。

五、备注
- 网页端本轮未改（仍为 2.9.0 的功能），version.json 升至 3.0.0 表示整个轻聊套件版本；
  下次部署网页时会同步显示 3.0.0 与本次更新说明。
- APK 二进制不入 Git（.gitignore），成品在 资料/游戏成果/轻聊/。
