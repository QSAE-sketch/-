轻聊 游戏成果（二进制不入库，仅索引）
======================================
- 轻聊.exe
    平台：Windows 7/10/11（64 位）原生客户端
    技术：C++ / Win32 + GDI 自绘 + GDI+ 图像，WinHTTP 联网，静态链接
    体积：约 666 KB（681472 B）
    位置：U 盘记忆库 资料/游戏成果/轻聊/轻聊.exe（离线副本）
- 轻聊-v3.1.0.apk　（当前版本，命名规则：轻聊-v<版本名>.apk，版本号取 version.json）
    平台：Android 原生客户端（Java，minSdk 21 / Android 5.0.2 起）
    技术：纯 Java Activity + 代码绘制 UI（无 XML 布局、无 WebView、无第三方依赖）
    体积：约 154 KB
    位置：本地工作副本 资料/游戏成果/轻聊/轻聊-v3.1.0.apk
    构建：见 资料/源码/轻聊/android/README.md（JDK17 + Gradle 8.9，assembleRelease）
    新增：外观·字体（6 款，双端）、皮肤星标置顶、金色特效开关改为彻底去金；
          非最初 14 套皮肤逐套压低荧光色，最初 14 套原样保留纪念
- 轻聊-v3.0.0.apk（历史版本，安卓原生端首版，仅作留档）
- 轻聊-v2.7.1.apk（历史版本，单页列表式，仅作留档）
版本：3.1.0（code 37）　更新：2026-11-28
说明：二进制产物不进 Git 主库（.gitignore 排除 apk/exe），需用时从本地工作副本取。

APK 功能（3.0.0，功能不再裁剪）：
- 界面：深蓝方角视觉，底部五页签（主页 / 房间 / 好友 / 网盘 / 我的），全部原生绘制
- 账号：登录 / 注册 / 多账号记忆 / 自动登录 / 改昵称 / 更换头像 / 注销 / 最高权限激活
- 聊天：公共聊天室 + 群聊 + 好友私聊；文字、图片（内联显示）、文件（分片上传、断点续传、下载）
        消息 2 分钟内撤回、删除仅自己隐藏、成员面板、站长金色流光（可在设置里关闭）
- 好友：好友申请（同意/拒绝）、账号名加好友、点好友直接私聊（私聊不进房间列表）
- 房间：新建 / 搜索加入（密码房）/ 成员 / 踢人 / 禁言 / 本房间昵称 / 离开
- 网盘：存储配额、我的文件 / 回收站 / 我的分享、搜索、类型与目录筛选、新建目录、
        移动 / 重命名 / 回收站 / 恢复 / 彻底删除、上传、分享（复用已有链接、可随时下线）
- 皮肤：皮肤中心读取网页皮肤的配色变量，57 套内置皮肤在原生端也能真正换色（默认原版）；
        可给喜欢的皮肤打星标，下次打开自动置顶
- 设置：外观·主题（跟随系统 / 按时间 / 手动）、外观·字体（系统默认/黑体/宋体/楷体/圆体/等宽）、
        最高权限账号金色特效开关（关掉彻底去金）、清除缓存 / 清除本机聊天记录、
        下载保存位置、服务器地址、关于与更新记录
- 兼容：Android 5.0.2（API 21）实测通过；浅色主题在 5.x 上自动加深状态栏，保证图标可见
