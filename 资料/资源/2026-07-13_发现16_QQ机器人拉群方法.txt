# 发现16：QQ 机器人加入 ≤20 人自建小群的方法（2026-07-13 晚）

## 结论
- 可以。≤20 人小群正好符合 QQ 开放平台【沙箱群】条件：群主 + 成员≤20（机器人自身算 1 个人头）。
- 本机「青少年」机器人、另一台「少年」的机器人均为独立机器人，互不影响、消息不互通。

## 操作步骤（情况 B：初连走频道/单聊，群里找不到）
1. bot.qq.com → 机器人 → 开发 → 沙箱配置 → QQ 群 ID 选目标群（须群主且≤20人）。
2. 保存 → 手机 QQ → 群设置 → 群机器人 → 添加。
3. 群里 @机器人 测试 WorkBuddy 是否响应。

## 情况 A（已在某群能用）：直接手机 QQ 群设置 → 群机器人 → 添加。

## 正式环境（不限人数/长期）
- 使用范围与人员 → 群 → 设"全量"（需审核）→ 群主可加任意群。

## 注意
- 新建号可能暂未开放群功能（改版频繁）；已连 WorkBuddy 并能私聊指挥的基本排除。
- 群场景接口能力有限（被动消息5分钟有效期、部分 API 不全）。
- 该端机器人收发须保持本机 + WorkBuddy 一直开着（非云端托管）。
