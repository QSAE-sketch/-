# Scratch 3.0 .sb3 格式关键发现

> 发现日期：2026-07-14
> 来源：把《悠闲钓鱼》Electron 游戏复刻成 Scratch .sb3 的实战，对照用户自己做的参考文件 Scratch作品1.sb3 定位根因。

## 1. 文件本质
- `.sb3` = ZIP 压缩包，根目录必须包含 `project.json` + 每个 costume 对应的 `.svg`（或 `.png`）资源文件。
- `project.json` 顶层结构：`{targets, monitors, extensions, meta}`。
- `targets` 第一个必须是 `Stage`（`isStage: true`），后面是 sprite。

## 2. 数字/字符串字面量格式
- 数字：`[1, [4, "0"]]`  ← **必须是字符串形式**，`[1, [4, 0]]` 会被某些加载器拒绝。
- 字符串：`[1, [10, "文本"]]`

## 3. 积木引用
- 引用另一个 block：`[2, "block_id"]`（tag 为 2）。
- 嵌套在 `inputs` 里的 block 必须有正确的 `parent` 指回父块，且 `topLevel: false`。
- **致命点**：非顶层块 `parent` 为 `null` 时，Scratch 加载器无法把它拼回父块，导致脚本区显示空白或加载失败。

## 4. event_broadcast 格式
- 只能有 `fields.BROADCAST_OPTION: [广播名, 广播id]`。
- 绝对不能带 `inputs.BROADCAST_INPUT`。

## 5. Stage 字段严格限制
- Stage 上只能有：
  - `isStage`, `name`, `variables`, `lists`, `broadcasts`, `blocks`, `comments`, `currentCostume`, `costumes`, `sounds`, `layerOrder`
  - `tempo`, `volume`, `videoState`, `videoTransparency`, `textToSpeechLanguage`
- **Stage 不能带 sprite 专属字段**：`x`, `y`, `size`, `direction`, `draggable`, `rotationStyle`, `visible`。

## 6. 变量/列表/广播作用域
- 全局变量/列表/广播统一注册在 Stage 上。
- 各 sprite 通过 `fields.VARIABLE: [变量名, 变量id]` 引用，id 必须在全局池里找得到。

## 7. Monitor 格式
- 变量监视器写法：
  ```json
  {
    "id": "变量id",
    "mode": "default",
    "opcode": "data_variable",
    "params": {"VARIABLE": "变量名"},
    "spriteName": null,
    "value": 0,
    "width": 0,
    "height": 0,
    "x": 0,
    "y": 0,
    "visible": true,
    "sliderMin": 0,
    "sliderMax": 100,
    "isDiscrete": true
  }
  ```

## 8. Costume 字段
- 必须有 `assetId`, `md5ext`, `dataFormat`, `rotationCenterX`, `rotationCenterY`, `bitmapResolution`（通常 `1`）。
- 资源文件名 = `{assetId}.{dataFormat}`，且必须出现在 ZIP 包里。

## 9. Meta 格式（桌面版 Scratch 3.32.0）
```json
{
  "agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Scratch/3.32.0 Chrome/148.0.7778.97 Electron/42.0.1 Safari/537.36",
  "semver": "3.0.0",
  "vm": "13.7.4-svg",
  "origin": "https://scratch.mit.edu",
  "savedOn": "2026-07-14T00:00:00+00:00",
  "mode": "editor"
}
```

## 10. 校验口诀
- 角色有 sprite，每个 sprite 有 topLevel 积木。
- 嵌套块 parent 非 null。
- 引用不断链。
- 广播走 fields。
- 数字是字符串。
- Stage 不带 sprite 字段。
