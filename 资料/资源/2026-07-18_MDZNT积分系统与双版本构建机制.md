# MDZNT 积分系统设计与双版本构建机制

> 来源：2026-07-18 给 MDZNT 桌面版（自用版 + 便携版）加积分系统，并重打包两个 EXE。
> 可作为后续同类「本地 AI 桌面应用 + 云端 API 限额」项目的可复用模板。

## 一、积分规则（桌面版）

- 总积分：各版本统一 **1000 点**。
- 刷新周期：**每周一 0:00**（按 `isoweekday()` 算本周一，不是简单 +7 天）。
- 扣点公式（按提问字数）：
  - `len <= 100` → 1 点
  - `100 < len <= 200` → 2 点，以此类推（每多 100 字 +1）
  - `len > 500` → 封顶 **10 点**
  - 实现：`ceil(n/100)`，超 500 直接返回 10。
- **云端 AI 才扣，本地 Ollama 无限**：以模型 id 是否带 `zhipu:` 前缀判定（`_is_zhipu(model)`）。
- **最后一条豁免**：剩 1 点时，无论多长都放行（`can_send` 里 `credits != 1` 才拦截）。
- 持久化：`credits.json` 存 `{anchor, credits}`，anchor = 当前周期起点；加载时若 anchor 与当前周期不符即重置。

## 二、双版本差异（关键）

| 维度 | 自用版 | 便携版 |
|---|---|---|
| `IS_PORTABLE` | False | True |
| 云端模型 | 可自由切所有智谱模型 | **锁定免费 `glm-4-flash`**（`ZHP_MODEL_MAP` 仅留免费项 → 模型商城自动只显示它）|
| 积分耗尽 | **不拦截**，用完也能继续用（`enforce=False`）| **拦截**云端，提示切本地（`enforce=True`）|
| API Key | 用户 setting 里填 | 放 `MDZNT便携版/mdznt_config.json`（exe 同目录）|

- 便携版也接智谱，但 `ZHP_MODEL_MAP` 在 `__init__` 里被覆盖成 `{FREE_CLOUD_ID: FREE_CLOUD_API}`，从而模型商城自动隐藏其它付费云端模型。

## 三、CreditSystem 类（核心代码模板）

放在 `workbuddy_chatbot.py`，`__init__` 里实例化：

```python
self._credit = CreditSystem(
    storage_base=self._get_storage_base(),
    max_credits=1000, refresh="weekly",
    enforce=self._is_portable,   # 便携 True / 自用 False
    is_local_unlimited=True)
```

- `calc_cost(text)` / `can_send(text)` / `consume(cost)` / `maybe_refresh()` / `next_refresh()` / `info()`。
- `stream_chat` 接入点（仅云端模型扣）：
  ```python
  if self._is_zhipu(model):
      self._credit.maybe_refresh()
      ok, cost = self._credit.can_send(q)
      if not ok:
          if not self._credit.enforce:
              self._credit.consume(cost)   # 自用版：放行
          else:
              yield "error", "积分不足…"; return
      else:
          self._credit.consume(cost)
  ```
- 前端查积分：主界面头像（`userAvatar`）点击 → `api.get_credit_info()` → 左上角灰色 toast（3 秒）显示剩余/总积分/下次刷新时间。toast 需 `white-space: pre-line` 才能换行。

## 四、双 EXE 构建机制（弱机必须串行）

- `version_tag.py` 里 `IS_PORTABLE` 在**编译期**决定版本；`app_launcher.py` `from version_tag import IS_PORTABLE`。
- 两个 spec（`MDZNT.spec` / `MDZNT_portable.spec`）共用同一份源码，仅靠 `version_tag.py` 区分。
- datas 把 `index.html` + `workbuddy_chatbot.py` 一起打进 EXE，所以改完前端/逻辑必须重打包才生效。
- 流程：
  1. `version_tag.py = False` → `pyinstaller --noconfirm MDZNT.spec` → `dist/MDZNT.exe` → 复制到 `可执行文件/`（保留其 `mdznt_config.json`）。
  2. `version_tag.py = True` → `pyinstaller --noconfirm MDZNT_portable.spec` → `dist_portable/MDZNT.exe` → 复制到 `MDZNT便携版/`（保留 `portable-models/`、`一键启动.cmd`、说明）。
  3. 打完把 `version_tag.py` 复位 `False`。
- **弱机（机器 2）重任务串行**：一次只打一个，绝不并行；打包会高占 CPU/内存，可能卡顿，需先警告并获确认。venv 内已装 PyInstaller 6.21 + webview。
- 测试：`test_credit_desktop.py`（22 项断言：公式/刷新/最后一条豁免/本地不扣/便携拦截/自用不拦截/模型商城锁定/info 结构）全部通过。

## 五、补充（本轮：onedir 重打包 + 硬锁加固 + 积分教程 + 三版差异）

### 1. 便携版硬锁加固（API 层）
- 旧：仅 `ZHP_MODEL_MAP` 软锁（前端模型商城只显示免费 `glm-4-flash`），但 `set_model` 不校验，API 层能强制切到付费云端（实测 `zhipu:glm-4.7` 可切入）。
- 新：`set_model` 内对便携版任何付费智谱 id 强制收敛回 `glm-4-flash`（免费），切不动。`detect_optimal_model` 本来就永不切走云端模型。
- 验证：`_verify_pass1.py` 实测 `set_model('zhipu:glm-4.7')` → 实际仍为 `glm-4-flash`。

### 2. onefile → onedir（治"一直重连"）
- 根因：旧版 onefile 每次启动自解压 + Windows Defender 实时扫描，启动慢；前端等不及触发一次性"重连/重载"兜底（被误认为连不上）。
- 改 onedir：文件常驻磁盘、不每次解压，启动快；前端连接失败宽限 6s→15s。
- spec 本就是 onedir 结构（`EXE(exclude_binaries=True)` + `COLLECT`）。

### 3. spec COLLECT name 修复（关键坑）
- 便携版 spec 的 `COLLECT(name='MDZNT')` 与自用版**同名**，导致两版都输出到 `dist/MDZNT/` 互相覆盖（查 `dist/MDZNT_portable` 一直缺失误以为失败）。
- 改便携版 `COLLECT(name='MDZNT_portable')` → 输出 `dist/MDZNT_portable/`，两版分目录。
- 正确流程：自用版→`dist/MDZNT/`；便携版→`dist/MDZNT_portable/`。

### 4. 积分教程页（写进 EXE 资源，需重打包生效）
- 桌面版内置新手 guide（`index.html` 的 `guide-step`）新增「💎 积分是什么」页（插在"下载模型"后）：本地模型不扣 / 云端扣、成本公式、每周一 0 点重置 1000 点、点头像看剩余、便携版用完切本地、免费模型也占额度。
- 便携版外部 `使用说明.txt` 补「💎 积分说明」节。
- 网页版无设置项、无内置教程，故不写教程。

### 5. 三版本积分判定差异（设计差异，非 bug）
| 版本 | 成本公式 | 判定策略 |
|---|---|---|
| 网页版 | ≤100字=1，每100+1，>500封顶10 | 整点刷 10 点；`cost>credits` 即拒（**无"剩1点放行"特例**）|
| 桌面自用版 | 同上 | `enforce=False`，**积分耗尽也不拦**，照常放行 |
| 桌面便携版 | 同上 | `enforce=True`，积分=0 拦截，但**剩1点放行最后一条** |

公式三版完全一致；上述差异是当初设计（自用无限用、便携限云端、网页按小时共享）。唯一不一致："剩1点放行最后一条"仅桌面有、网页版无。

### 6. 字数统计零影响 AI 速度
- `len()` 是 O(1)。实测 100 万次 `len()` 仅 213–332ms，单次 0.2–0.3μs。AI 回答耗时在模型推理（百毫秒~秒级），字数统计可忽略。

### 7. OpenClaw（不接入）
- 用户本机已装好 OpenClaw 并配置，且与 MDZNT **共用同一模型**（本地 Ollama 同一个）；OpenClaw 是需在终端敲命令启动的独立工具，不嵌入 MDZNT。
- 结论：MDZNT 无需接入 OpenClaw，"能不能接入"为随口一问，未改代码。
