## 1. 神经进化游戏 AI 脚手架（可复用）

- 桌面 pygame 封装 + PyInstaller 打包；监控面板**别挡游戏地图渲染**（否则看 AI 玩无反应）。

## 2. AI 出图 → 图层分割流水线
- 先出高分辨率原画 → 去水印抠透明 → `split_layers.py` 按颜色 / 连通域分层 → 头发细分 v6 到 8 层适配 Live2D Cubism。
- 坑：numpy int64 不能直接 JSON 序列化 → 转 python int 再存。

## 3. LSTM 字符模型（CharAI）
- seq2seq 双向（描述 → 字符 / 字符 → 描述），5416 对数据集。
- 数据量小 → 反向易过拟合（Val 0.66 vs 正向 0.05）；可直接封装 Skill。
