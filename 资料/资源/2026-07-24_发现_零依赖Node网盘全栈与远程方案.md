# 发现：零依赖 Node 网盘全栈 + 远程方案（2026-07-24，quark-netdisk）

- 零依赖 Node 全栈：`server.js`（8787）单密码 / 目录隔离 / 流式上传 / Range 视频 / 分享链接 / **路径穿越防护**；暗色前端。
- 坑：`pepper` 写死、`resolveSafe` 漏 hidden file。
- 自写 ZIP 打包下载（**手写 CRC32**，避免外部依赖）。
- 打包：PyInstaller + pywebview → `QuarkDisk.exe`（46MB）；两实例分开（appdata vs 项目 storage）。
- 远程：`cloudflared` 被墙 → `ssh localhost.run` 隧道；安卓 APK 走 GitHub Actions；PWA 可加主屏。
