# 发现：安卓模拟器（守·安卓模拟器）全栈调试知识（2026-08-06，归档前未进库）

> 模拟器便携化归档见 事件/2026-08-07_事件_守安卓模拟器便携化与记忆库归档.md；本条是构建/调试的细粒度发现。

- WHPX 启用后装机 2 分 → 30 秒；分辨率 `nomodeset` + `UVESA_MODE` / 注册表 `HIGHDPIAWARE`。
- APK 引擎指纹检测（Unity / Unreal ARM-only 禁用安装）；houdini（ARM 翻译）能跑 → 改兼容 notes。
- 网络 e1000 + 动态接口名（wlan0）；本机硬件检测 `host_info`；离线整包 2.25GB。
- 打包 bug：spec 路径 / GRUB 补丁；首屏检测慢（DISM）→ 2.75s；DirectBoot 绕过 GRUB；黑窗 `CREATE_NO_WINDOW`；VM 自动发现 + 导入。
- 依赖复用：junction 层 + 下载加 PATH + auto_reuse；图标生成。
- **铁律**：PyInstaller 必须用 `envs/default` + onedir；WebView2 弱机补丁（升级会丢）；QEMU 中文路径用 junction 层 + 三连坑。
- 钓鱼游戏转悠闲钓鱼.apk 用本地 Gradle。
