# 2026-08-07 发现：C盘爆满诊断与清理（机器2 LAPTOP-6NCCT3NN）

## 诊断方法（可复用）
- C盘剩余：`Get-PSDrive C`（看 Used/Free）。本次初始 184.7GB 总量、仅 5.25GB 可用(97%)。
- **非提权 shell（IS_ADMIN=False）下，DISM /AnalyzeComponentStore、vssadmin 均报权限不足**——系统级清理（WinSxS、还原点、WSL compact）需管理员 PowerShell。
- 用户目录分布用 `Get-ChildItem -Recurse -Force | Measure-Object Length -Sum` 递归量大小；**裸用会遇超长路径/权限终止错误导致整脚本崩**，必须改成：逐目录独立 try/catch、算完一条就 `Out-File -Append` 一条（容错写法见本次 cscan2/cscan3）。
- 二级细分：AppData 下 Local/Roaming/LocalLow 各子文件夹逐个量，定位具体程序。

## 本次实测大头（机器2 C盘 用户目录）
- AppData 44.65GB：wsl 15.83 / Local\Programs 7.65(VS1.09+Ollama2.74+Quark3.81) / Tencent 3.36 / kingsoft 1.24 / Microsoft 1.49 / Packages 1.07
- Documents 23.19GB：WeChat Files 20.04（Image+Video+File+Msg）
- Desktop 18.88GB：无用13.21 / 安卓模拟器3.63（已删）/ MyOS.iso 1.9
- 纯系统临时（Windows\Temp、Local\Temp、INetCache、npm-cache、回收站）都很小，**不是元凶**——别在临时文件上浪费时间，大头都在用户个人目录。

## 微信安全清理粒度（关键）
- `Documents\WeChat Files\<账号>\FileStorage\` 下：
  - Image / Video = 媒体缓存（可删，聊天里重下即恢复）
  - File = 别人发的文档/安装包（可删）
  - Msg* = 聊天记录数据库（**不删**）
- 清媒体 + File 腾最多空间，聊天文字记录保留。本次清媒体6.82G + 文档2.96G。

## WSL 虚拟硬盘
- AppData\Local\wsl 15.83GB 是 WSL2 的 ext4.vhdx，搞系统用须保留；可 compact 回收未用空间但**需管理员**（`wsl --shutdown` 后 diskpart `compact vdisk`）。普通非提权 shell 做不了。

## Local\Programs 真相
- 不是垃圾，是三个在用软件：VS Code(开发)、Ollama(本地AI)、Quark(夸克)。删了要重装，别当缓存清。
