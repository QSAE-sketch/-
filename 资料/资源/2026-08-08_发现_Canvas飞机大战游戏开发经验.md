# 发现 · Canvas 飞机大战游戏开发经验（单文件零依赖范式）

日期：2026-08-08
类型：HTML5 Canvas 游戏架构 + 常见崩溃坑
本体样例：资料/游戏成果/飞机大战/index.html（D:\plane-game\index.html）

## 一、架构范式（可复用骨架）
- 单 `.html` 文件，内联 `<style>` + `<script>`，零外部依赖，浏览器双击即玩。
- 主循环：`requestAnimationFrame` 驱动 `update()` + `draw()`。
- 状态机：`gameState = 'menu' | 'playing' | 'gameover'`，非 playing 时停更只画背景。
- 实体用纯对象数组：`bullets / enemies / enemyBullets / particles / powerups / floatTexts`。
- 碰撞：矩形用 `rectOverlap(ax,ay,aw,ah, bx,by,bw,bh)`（中心+半宽高）；圆用 `circleRect`。
- 关卡推进：敌机全灭（`enemies.length===0`）→ 出BOSS → BOSS死 → 延迟刷下一波。

## 二、3个致命坑（本次实测踩过，已修）
1. **BOSS击杀后空引用崩溃**
   - 现象：狂怒5连发穿透弹同一帧多次命中BOSS，第一颗把 `boss.hp` 打到0→`killBoss()`→`boss=null`；循环继续拿第二颗弹访问 `boss.x`，直接 `TypeError` 卡死。
   - 修复：在 `if (boss.hp <= 0) { killBoss(); break; }` 里 `killBoss()` 后立即 `break` 退出子弹循环。

2. **敌机不清理→关卡卡死**
   - 现象：敌机 `e.y += speed` 飞出屏幕底部后从不移除，永远留在 `enemies` 数组 → `enemies.length` 永不为0 → "全灭才出BOSS"条件永不触发 → 打光也出不了BOSS。
   - 修复：每帧 `enemies = enemies.filter(e => e.y <= H + 60);` 清掉离屏敌机。

3. **预览缩放后鼠标坐标偏移**
   - 现象：嵌入预览窗口把 canvas 缩放显示，`e.clientX-rect.left` 得到的是显示像素，和画布内部分辨率不一致→飞机跟着鼠标偏。
   - 修复：`x = (e.clientX-rect.left) * (W/rect.width)`，`y = (e.clientY-rect.top) * (H/rect.height)`。

## 三、2个易漏点（本次也修了）
- **关卡过渡防重刷**：BOSS死后下一帧 `enemies` 空、`boss=null`，条件 `!boss && enemies.length===0` 立刻成立→立刻又刷BOSS。加 `levelTransition` 标志，过渡期（含延迟刷敌机）屏蔽BOSS生成。
- **延迟定时器需清理**：`setTimeout` 刷下一波敌机，游戏结束/重开时不 `clearTimeout` 会触发旧定时器。用 `bossDeathTimer` 记录 ID，结束/重开时 `clearTimeout`。

## 四、可复用结论
- 任何"实体数组 + 全灭才进下一阶段"的关卡游戏，**离屏实体必须清理**，否则关卡会卡死。
- 任何"死亡即置null"的对象，其遍历循环里置null后要**立即 break/continue** 退出对该对象的访问。
- 鼠标/触摸坐标**永远按 canvas 显示比换算**，不要直接用 clientX。
