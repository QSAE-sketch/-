# 2026-09-01 发现：丧尸时节 sb3 手工构造与 Scratch 战斗系统坑

## 背景
用 Python 直接读写 sb3 的 project.json 改造 Scratch 游戏（不靠 Scratch 编辑器拖块），踩的坑与可复用范式。

## 发现
1. **sb3 结构**：zip 包，根 `project.json` 是全部逻辑；targets[0]=舞台(stage)，其余精灵。变量分 stage 全局与精灵私有。
2. **input 阴影标志必须整数**：Scratch 3 block input 数组第一元素是阴影标志，必须是整数 `1`(有阴影)/`2`(无阴影)，写成字符串 `"1"` 会被 TurboWarp 校验拒绝（validationError: should be number）。
3. **input 格式范式**：
   - 引用其他块：`[1, blockId]`
   - SUBSTACK / CONDITION：`[2, blockId]`
   - 文字/数字字面量：`[1, [10, "值"]]`（10=数字，11=广播，12=变量引用）
   - 广播：`[1, [11, "消息名", "广播id"]]`
   - 变量读：`data_variable` 块，fields `VARIABLE: ["变量名", "变量id"]`
4. **菜单阴影块**：opcode 带 `_menu` 后缀（如 `motion_pointtowards_menu`），fields 写 `[值, null]`，被主块 inputs 引用。
5. **克隆计数必须全局**：生成上限计数（如"可容叔"）放 stage 全局；放精灵私有会让每个克隆体各持一份副本 → 计数器永不增长 → 无限刷怪或永不生成。
6. **精灵私有变量 = 每克隆体独立**：如僵尸血量放敌人精灵私有，每个克隆体自动独立一份，是做"每个怪物独立血条"的正确方式。
7. **子弹命中竞态**：命中判定放"被击中方"（僵尸 `touching 子弹` 减血），且把子弹精灵在 targets 中排在敌人之后，保证每帧僵尸先执行、子弹后删自己，避免"子弹先消失僵尸没掉血"的一帧丢失。
8. **玩家移动最稳写法**：用 4 个 `event_whenkeypressed`（上下左右）帽子，直接 `motion_changexby/yby`；不要用 `control_forever + sensing_keypressed`（TurboWarp 下不触发）。
9. **绿旗补播既有广播**：重建时若需触发原文件的 `when I receive` 接收端，广播 id 必须从 stage['broadcasts'] 取已存在的，不能自造 id，否则接收端收不到。
10. **装备 UI**：用独立精灵 + 多个 SVG costume（每武器一造型）显示在角落，`looks_switchcostumeto` 按编号切；切换靠 `event_whenthisclicked`（点精灵）或 `event_whenkeypressed`(e) 广播。
