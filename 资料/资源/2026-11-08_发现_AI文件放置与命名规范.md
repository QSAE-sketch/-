# 2026-11-08 发现：AI 文件放置与命名规范（大佬硬性要求，强制）

> 背景：大佬对 AI 把测试虚拟机堆在 C 盘、把产物/临时文件散在 D 盘根、英文文件名看不懂等问题强烈不满。
> 以下为面向「少年（WorkBuddy AI）」的强制行为规范，下次务必遵守，不要再犯。

## 一、C 盘：严禁堆放、能删就删
- C 盘空间严重不足；里面的东西多为英文、且需管理员权限才能动，大佬看不懂也不敢乱删。
- **禁止**把测试用的虚拟机、大体积临时文件、构建缓存等放 C 盘。
- 测试不需要的东西（尤其是手机端环境本机无法模拟的测试 VM）**直接删掉**，别留着占空间。
- 若确需在 Windows 上做系统级测试，优先用 D 盘（还有一大半空间），不要碰 C 盘。

## 二、D 盘根目录：禁止直接扔文件
- **不要把文件/文件夹直接丢在 D 盘根目录**（尤其英文名的），大佬找文件、删东西都很痛苦。
- 文件一律放进「工作空间」：WorkBuddy 的项目工作目录（如 `D:\.workbuddy\<会话目录>\` 下的项目目录）。
  大佬基本不看工作空间内部，你在里面怎么命名都行，但外层别冒出来英文散件。
- 尽量用**中文命名**；实在只能英文的，也放工作空间里，别散在 D 盘根。

## 三、中文 / 英文 放置细则
- 能用中文命名的 → 可以简洁地放 D 盘（如 `D:\轻聊\`）。
- 只能用英文的 → **放工作空间里**，不要放 D 盘根。
- 若大佬要求放 D 盘但内容必须英文 → 在 D 盘建一个**中文名总文件夹**（如 `D:\我的应用\`），里面随便怎么命名都行，但外层目录必须中文。

## 四、产物（APK / 桌面 exe）策略
- 网站类应用：常规更新**只改线上内容**即可，无需重新构建 APK/exe。
- APK / exe **不必每次都测试**：只要保证"能装能用、无严重 bug"即可；手机端环境本机无法模拟，测试 VM 没意义。
- 版本号**只在设置页「关于」展示**，产物文件名不带版本号后缀（近期策略不变）。
- 旧产物：不更新也行就保留，或按大佬要求改成中文名挪到 D 盘；**不要留在 C 盘或 D 盘根**。

## 五、一句话总结（给少年的硬规矩）
C 盘不要碰、D 盘根不要扔英文散件、能删的测试垃圾就删、产物随线上走不必重测、命名尽量中文、放不下的进工作空间。
