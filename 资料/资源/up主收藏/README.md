# up主收藏（固定文件夹）

本文件夹由 OpenClaw 的 **up-collect** skill 专用，存放用户收藏的 B站 up 主资料。

## 规则

- 每个 up 主一个 `<up主名>.md` 文件，内容为该 up 主的昵称、简介、粉丝量级、代表作、收藏日期、来源链接。
- **只有 up-collect skill 会往这里写**，且写前会先通过哨兵 `__WORKBUDDY_KB_ID__` 定位本 U 盘盘符，再写入 `资料/资源/up主收藏/`。
- 本文件夹**不属于 workbuddy-kb 记忆库**，请勿把记忆库资料（事件/成果/技术要点）挪进这里，也不要把这里的 up 主文件挪进记忆库。
- agent 被硬性禁止写到除本文件夹以外的任何位置（含 `验证/`、`workbuddy-kb/`）。

## 用途

- 看 B站时随口说「收藏这个 up 主 XXX」，OpenClaw 自动抓资料存这里。
- 日后用 `kb-recall` 或手动翻本文件夹，即可回顾收藏过哪些 up 主。
