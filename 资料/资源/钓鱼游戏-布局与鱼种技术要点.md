## 1. 「背景不能动」布局系统的最终解法
单 HTML 游戏做拖拽布局时，面板脱离文档流会导致父容器塌缩/背景抖动。踩了很多坑，最终稳定方案：

- **Flexbox 骨架**：`.app{display:flex;flex-direction:column}`，`.topbar/.bottom{flex-shrink:0}`，`.stage{flex:1;overflow:hidden}`。
- **min-height 锁定**：`lockParent(el)` 用 `getBoundingClientRect().height` 把 topbar/bottom/stage 的高度锁死，`dataset.locked` 做守卫防重复锁。
- **闭环规则**（关键）：
  - 进入布局模式 → 先清旧锁 → 面板归位 → `requestAnimationFrame` 里锁高度 → 再搬运有坐标的面板。
  - 退出布局模式 → **不解锁**（保持高度，避免页面缩小）。
  - 重开 applyLayout → 清锁 → 放面板 → raf 重锁。
  - 重置 resetLayout → 清锁 + 面板归位。
- **兜底**：`unlockAllParents()` 直接清 DOM 上的锁，防止 raf 异步锁把高度永久锁死。
- **标题防下掉**：`.title{align-self:flex-start}`（重构时容易丢，要记得补）。

## 2. 松手自动保存但不退出
拖拽 pointerup 时自动 persist 坐标到 `save.settings.layout={id:{x,y}}`，但**只有点「✅保存并退出」才退出布局模式**。load() 里不要 `delete layout`，否则保存丢失。

## 3. 上鱼概率按百分比随机（更真实）
之前是进度>50% 一刀切必中，不合理。改为：
```js
if(S.reelTime>=S.reelLimit){
  if(Math.random()<S.fishPull) landFish();
  else escapeFish('鱼挣脱了…进度不足');
}
```
进度多少就有多大概率中鱼。

## 4. 关闭时托盘选项（main.js）
BrowserWindow + Tray + dialog：关闭时弹窗选「最小化到托盘」→ win.hide() 保留托盘图标；选「直接关闭」→ app.quit()。

## 5. 浏览器横屏顶部被截断
body 改 `display:flex; align-items:flex-start; justify-content:center; overflow-y:auto`，避免居中导致上方内容被裁。

## 6. 鱼种扩充规则
共 180 种，垃圾分布 湖泊>海洋>深渊：湖泊 61（8 垃圾）、海洋 63（3 垃圾）、深渊 58（2 垃圾）。shark/whale 跨 lake+sea 共享。鱼种的 time 字段只能用 any/day/night，不能用 fog/storm（上鱼逻辑不识别）。
