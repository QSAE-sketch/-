# 鱼图批量生成 + 战绩图改造技术要点

## 背景
钓鱼游戏需要为稀有/史诗/传说级鱼（共71条）生成专属AI美图，用于战绩图展示。用户要求"每条难钓的鱼都有高级图片"，风格为水墨金箔锦鲤风。

## 鱼图批量生成工作流

### 准备工作
1. 从 `FISH` 数组提取需要配图的鱼（`fish_to_generate.json`）：过滤 rarity 为 rare/epic/legend 的条目，共 71 条（25 rare + 23 epic + 3 legend？实际 epic 后来补齐）。
2. 创建输出目录 `fish-art/`。

### 生成流程（对每条鱼循环）
1. **检查**：`fish-art/{鱼名}.png` 已存在则跳过。
2. **调用 ImageGen**（通过 ToolSearch → DeferExecuteTool）
   - 先 `ToolSearch(tool_names=['ImageGen'])` 加载 schema
   - 再 `DeferExecuteTool(toolName='ImageGen', params={...})`
   - 参数：`size='1024x1024'`，`quality='high'`，`revise=false`，`output_dir='fish-art/'`
3. **Prompt 工程**（水墨金箔风格模板）：
   ```
   一幅中国风水墨画，一条{DESCRIPTION}的{NAME}在水中游动，{BODY_DESC}，水面泛起涟漪，淡墨远山和云雾背景，柔和粉彩色调，金箔高光，仙气飘飘，{RARITY_DESC}，高清，无水印，无文字，无字母
   ```
   - DESCRIPTION：鲨鱼→威猛，鲸→可爱，鳗→巨大修长，水母→晶莹剔透，龙虾/蟹→华丽铠甲，深海鱼→神秘幽暗，锦鲤/金鱼→华丽
   - BODY_DESC：贴合鱼种的身体配色质感描述
   - RARITY_DESC：epic→"史诗级气场，威武霸气"，rare→"稀有优雅，仙气飘飘"
4. **裁剪去水印**：ImageGen 生成的图底部有"图片由AI生成"水印，用 PIL crop((0,0,w,940)) 裁剪掉底部 84px，保存为 `{鱼名}.png`

### 容错
- 429 额度用尽：`sleep 60` 重试，最多 5 次
- 分批并发 4-5 张，避免触发频控

### 技术栈
- 图像生成：云端 ImageGen API
- 裁剪：Python PIL (Pillow)
- 路径：Git Bash 下用 `/c/Users/.../python.exe`

## 战绩图改造方案

### 核心改动（openShare 函数）
原为 canvas 程序化画鱼（drawFish/drawSeal），改为**异步加载 AI 真图**：

1. **圆形裁切进舞台环**：
   ```js
   const img=new Image();
   img.onload=()=>{
     x.save();
     x.beginPath(); x.arc(W/2,380,stageR-3,0,7); x.clip();
     const sc=Math.max((stageR*2)/img.width,(stageR*2)/img.height);
     x.drawImage(img, W/2-img.width*sc/2, 380-img.height*sc/2, img.width*sc, img.height*sc);
     x.restore();
     // 重设下载链接
     try{ dl.href=c.toDataURL('image/png'); }catch(e){}
   };
   img.onerror=()=>{ /* fallback drawFish/drawSeal */ };
   img.src='fish-art/'+encodeURIComponent(save.best.name)+'.png';
   ```
2. **舞台金边双环**：外金内青，半径 172
3. **下载按钮**：改为 onclick 时 toDataURL（避免异步图片未加载时导出空白）
4. **fallback**：图片缺失（普通/垃圾鱼无专属图）时回退程序化绘制
5. **图片路径**：相对路径 'fish-art/{name}.png'，需要把 fish-art 目录随 release 包放在 resources/app/fish-art/

### 注意事项
- canvas 加载 file:// 图片可能污染 -> 在 Electron 下通常不污染，拖到网页版测试可能污染，用 try/catch 兜底
- 没有专属图的鱼（common/uncommon/junk）→ 自动 fallback 到程序化绘制，不影响使用
