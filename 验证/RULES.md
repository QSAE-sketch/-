> U 盘「记忆库」仅作离线副本，规则全文不再以 U 盘为权威，详见第四节。

## 一、主库位置（已变更）
- **资料主库 = Git 仓库**：`https://github.com/QSAE-sketch/-`（公开）
- 本地工作副本：`D:\apk-download-site`
- U 盘「记忆库」仅作**离线副本**，不再作为主存；所有新增/修改以推送到 Git 为准。
- 同步命令：`git add -A` → `git commit -m "..."` → `git push origin main`

## 二、仓库资料为（分类结构）
仓库 `资料/` 下按原记忆库格式组织，共五大分类 + 总记录：

| 目录 | 内容 | 命名 / 规则 |
|---|---|---|
| `资料/事件/` | 任务/事件总结 | `日期_事件_主题.txt`；写入前先查重，同主题在原文件增补 |
| `资料/资源/` | 新发现 / 资料 | `日期_发现N_主题.txt` 或 `日期_主题.txt` |
| `资料/源码/` | 每个项目单独子文件夹 | 如 `源码/APK下载站/`、`源码/轻聊/`、`源码/云网盘/`；只放可重建源码，不含 node_modules / 构建产物 |
| `资料/素材库/` | 按来源单独子文件夹 | 如 `素材库/轻聊图标与素材/` |
| `资料/skills/` | 可复用技能 / 提示词 | 来自 U 盘 `资料/skills/` |
| `资料/资料总记录.txt` | 总日志 | UTF-8 BOM，新条目追加到末尾，不覆盖历史 |

**游戏成果（二进制大文件）不入库**：仅留 `说明.txt` 索引，记录产物位置与体积，不传 exe / iso / model 等。

## 三、上传方法及注意事项
- **推送方式**：本地 `D:\apk-download-site` → `git commit` → `git push origin main`。GitHub 认证走 Windows 凭据管理器（方案 1：首次 push 弹窗登录一次，凭据自动缓存）。
- **单文件上限 100 MB**（GitHub 限制）：超过则改留索引说明，不入库。
- **公开仓库脱敏**：同步前对 `app_secret / client_secret / access_token / password` 等**真实密钥值**替换为 `[已隐去]`；`appid`、账号等标识符保留。
- **不复制**到公开仓库：U 盘哨兵（`__WORKBUDDY_KB_ID__`）、规则原始版全文、含设备信息（主机名 / 路径）的历史总记录。
- **不破坏历史**：合并用 `git pull --rebase`，禁止强推（force push）。
- 每次任务后：事件/资源按格式归档 → 总记录末尾追加 → `commit + push`。
